# Sustainable Software Thesis

**Research Date:** 2026-03-24

This repository holds the research artifacts for a MIT graduate thesis on sustainable software development practices and carbon footprint measurement in software engineering. The project will explore best practices, develop a measurement framework, and analyze industry case studies.

## Project Scope
- Literature review of sustainability metrics and frameworks
- Design of a comprehensive carbon measurement methodology (SCI)
- Documentation of industry implementations and case studies

## Structure
- `docs/` – research documents and literature summaries
- `framework/` – methodology specifications and tools
- `case-studies/` – analyses of real-world implementations
